# herdr-mods

Mods for the [Herdr](https://herdr.dev) app. One folder per mod; each has its own `RECIPE.md`, `preview.png` and `mods/<name>/`.

| Mod | What it does |
|---|---|
| [claude-config](claude-config) | Panel listing Claude Code plugins, MCP servers and skills for the current project, with their source (global / repo / local) and on/off switches. |
| [pull-requests](pull-requests) | Panel listing the PRs of the current repo with label chips, Open/Merged/All filters and a Mine filter. Click a PR to review it in a pane: conversation with label changes, review threads and their status, file diffs, merge status, and a GitHub-style merge button with Convert to draft / Close / Archive (needs the GitHub CLI). |
