# herdr-mods

Mods for the [Herdr](https://herdr.dev) app. One folder per mod; each has its own `RECIPE.md`, `preview.png` and `mods/<name>/`.

| Mod | What it does |
|---|---|
| [claude-config](claude-config) | Panel listing Claude Code plugins, MCP servers and skills for the current project, with their source (global / repo / local) and on/off switches. |
